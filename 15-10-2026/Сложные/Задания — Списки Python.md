# Практическая работа: списки в Python

**Продолжительность:** одна пара — примерно 90 минут.

Задания рассчитаны на тех, кто уже знаком с циклами, условиями, индексами и срезами. Готовые решения не прилагаются.

## Общие требования

- Каждое задание оформить отдельной функцией.
- Кроме примера из условия, проверить функцию минимум на трёх собственных примерах.
- Исходный список не изменять, если в условии не сказано обратное.

## 1. Удаление повторов с сохранением порядка — 10 минут

Напишите функцию `unique_ordered(numbers)`, которая возвращает новый список без повторяющихся элементов. Сохраняется первое появление каждого числа.

**Ограничение:** нельзя использовать `set` и словари.

```python
unique_ordered([4, 2, 4, 7, 2, 9, 7, 1])
# [4, 2, 7, 9, 1]
```

Проверьте работу на пустом списке и списке, где все элементы одинаковые.

## 2. Циклический сдвиг — 10 минут

Напишите функцию `rotate(numbers, k)`, которая циклически сдвигает список:

- при положительном `k` — вправо;
- при отрицательном `k` — влево;
- при нулевом `k` — оставляет порядок прежним.

Число шагов может быть больше длины списка. Пустой список должен обрабатываться без ошибки.

```python
rotate([10, 20, 30, 40, 50], 2)
# [40, 50, 10, 20, 30]

rotate([10, 20, 30, 40, 50], -1)
# [20, 30, 40, 50, 10]

rotate([1, 2, 3], 8)
# [2, 3, 1]
```

**Условие:** не выполнять сдвиг по одному элементу `abs(k)` раз.

## 3. Сжатие последовательности — 15 минут

Напишите функцию `compress(numbers)`, которая заменяет каждую группу **подряд идущих одинаковых чисел** списком `[число, количество]`.

```python
compress([5, 5, 5, 2, 2, 5, 8, 8])
# [[5, 3], [2, 2], [5, 1], [8, 2]]
```

Затем напишите функцию `decompress(groups)`, которая восстанавливает исходный список.

```python
decompress([[5, 3], [2, 2], [5, 1], [8, 2]])
# [5, 5, 5, 2, 2, 5, 8, 8]
```

Для любого списка должна выполняться проверка:

```python
decompress(compress(numbers)) == numbers
```

## 4. Анализ скользящего окна — 15 минут

Даны список чисел и размер окна `k`. Окно — это `k` соседних элементов. Оно перемещается по списку на одну позицию.

Напишите функцию `window_sums(numbers, k)`, которая возвращает суммы всех окон.

```python
window_sums([4, 1, 7, 2, 6], 3)
# [12, 10, 15]
```

Дополнительно найдите **индекс начала первого окна с максимальной суммой**. В примере это индекс `2`.

**Условия:**

- При `k <= 0` или `k > len(numbers)` возвращать пустой список; индекс максимального окна в этом случае — `None`.
- После вычисления суммы первого окна получать следующую сумму через вычитание уходящего и прибавление нового элемента.
- Не применять `sum()` отдельно к каждому окну.

## 5. Самая длинная возрастающая серия — 20 минут

Напишите функцию `longest_increasing_run(numbers)`, которая возвращает самый длинный **непрерывный** участок списка, где каждый следующий элемент строго больше предыдущего.

Если подходящих участков несколько, вернуть первый.

```python
longest_increasing_run([3, 5, 7, 2, 4, 6, 8, 1])
# [2, 4, 6, 8]

longest_increasing_run([1, 2, 2, 3, 4])
# [2, 3, 4]

longest_increasing_run([9, 7, 5])
# [9]
```

Для пустого списка вернуть `[]`.

**Условие:** пройти исходный список один раз. Равные соседние элементы прерывают возрастание.

## 6. Поворот матрицы — 20 минут

Матрица задана списком списков одинаковой длины. Напишите функцию `rotate_matrix(matrix)`, которая возвращает новую матрицу, повёрнутую на **90 градусов по часовой стрелке**.

```python
rotate_matrix([
    [1, 2, 3],
    [4, 5, 6]
])
# [
#     [4, 1],
#     [5, 2],
#     [6, 3]
# ]
```

**Требования:**

- Функция должна работать и с прямоугольными матрицами.
- Исходную матрицу изменять нельзя.
- Нельзя использовать NumPy и `zip`.
- Для пустой матрицы вернуть `[]`.

Проверьте результат на квадратной матрице, одной строке и одном столбце.

## Дополнительное задание для тех, кто закончил раньше

Напишите функцию `max_sum_segment(numbers)`, которая находит непрерывный непустой участок с максимальной суммой и возвращает сам участок и его сумму.

```python
max_sum_segment([-2, 3, -1, 4, -5, 2])
# ([3, -1, 4], 6)

max_sum_segment([-8, -3, -6])
# ([-3], -3)
```

Если максимальная сумма встречается у нескольких участков, выбрать участок с наименьшим индексом начала, а при одинаковом начале — самый короткий. Для пустого списка вернуть `([], 0)`.

**Усложнение:** решить за один проход без перебора всех возможных участков.
