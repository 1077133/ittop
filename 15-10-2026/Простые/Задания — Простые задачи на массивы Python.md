# Простые задачи на массивы в Python

В этой работе массивы представлены списками Python. Для решения достаточно знать переменные, условия, циклы и обращение к элементам по индексу.

## Общие требования

- Каждую задачу решить отдельной программой.
- Список целых чисел вводить с клавиатуры одной строкой через пробел.
- Индексы считать с нуля.
- Проверить каждую программу на примере из условия и на своём примере.
- Во всех задачах можно считать, что список содержит хотя бы одно число.

Пример ввода списка:

```python
numbers = list(map(int, input().split()))
```

## 1. Вывод элементов

Выведите каждый элемент списка на отдельной строке.

**Ввод:**

```text
4 7 2
```

**Результат:**

```text
4
7
2
```

## 2. Сумма элементов

Найдите сумму всех элементов списка.

**Ограничение:** не использовать `sum()`.

**Ввод:**

```text
3 5 -2 4
```

**Результат:**

```text
10
```

## 3. Количество положительных чисел

Посчитайте, сколько элементов списка больше нуля. Ноль не считается положительным числом.

**Ввод:**

```text
-3 5 0 8 -1 2
```

**Результат:**

```text
3
```

## 4. Только чётные числа

Создайте новый список, содержащий только чётные числа исходного списка. Сохраните их порядок. Если чётных чисел нет, результатом будет пустой список.

**Ввод:**

```text
7 4 0 9 -2 5
```

**Результат:**

```text
[4, 0, -2]
```

## 5. Максимальный элемент

Найдите наибольшее число в списке.

**Ограничение:** не использовать `max()` и сортировку.

**Ввод:**

```text
-8 -3 -10 -5
```

**Результат:**

```text
-3
```

## 6. Поиск числа

После списка введите отдельной строкой число `x`. Выведите индекс его первого появления. Если такого числа нет, выведите `-1`.

**Ограничение:** не использовать `index()`.

**Ввод:**

```text
4 7 2 7 9
7
```

**Результат:**

```text
1
```

## 7. Сколько раз встречается число

После списка введите отдельной строкой число `x`. Посчитайте количество его появлений в списке.

**Ограничение:** не использовать `count()`.

**Ввод:**

```text
2 5 2 8 2 1
2
```

**Результат:**

```text
3
```

## 8. Замена отрицательных чисел

Замените все отрицательные элементы списка нулями. Измените исходный список и выведите его.

**Ввод:**

```text
4 -2 7 -8 0
```

**Результат:**

```text
[4, 0, 7, 0, 0]
```

## 9. Первый и последний

Поменяйте местами первый и последний элементы списка. Если элемент только один, список остаётся прежним.

**Ввод:**

```text
10 20 30 40
```

**Результат:**

```text
[40, 20, 30, 10]
```

## 10. Элементы на чётных индексах

Создайте список из элементов, стоящих на индексах `0, 2, 4, ...`.

Обратите внимание: проверять нужно индекс элемента, а не чётность самого числа.

**Ввод:**

```text
9 8 7 6 5 4
```

**Результат:**

```text
[9, 7, 5]
```

## 11. Больше предыдущего

Выведите списком все элементы, которые больше своего непосредственного левого соседа. Первый элемент не проверяется. Если подходящих элементов нет, выведите пустой список.

**Ввод:**

```text
3 7 4 6 6 9
```

**Результат:**

```text
[7, 6, 9]
```

## 12. Список в обратном порядке

Создайте новый список, в котором элементы исходного списка расположены в обратном порядке.

**Ограничение:** не использовать `reverse()`, `reversed()` и срез `[::-1]`. Используйте цикл.

**Ввод:**

```text
1 4 7 9
```

**Результат:**

```text
[9, 7, 4, 1]
```

## Дополнительные задачи

### 13. Больше среднего

Найдите среднее арифметическое элементов списка. Затем выведите списком все числа, которые строго больше среднего, сохраняя их порядок.

**Ввод:**

```text
2 4 6 8
```

**Результат:**

```text
[6, 8]
```

### 14. Проверка порядка

Определите, расположен ли список по неубыванию: каждый следующий элемент должен быть больше предыдущего или равен ему. Выведите `ДА` или `НЕТ`. Список из одного элемента считается упорядоченным.

**Ограничение:** не использовать сортировку.

**Ввод:**

```text
1 3 3 7 9
```

**Результат:**

```text
ДА
```

### 15. Суммы двух списков

Введите два списка целых чисел одинаковой длины, каждый с отдельной строки. Создайте третий список: каждый его элемент равен сумме элементов двух исходных списков с тем же индексом.

**Ввод:**

```text
1 2 3
4 5 6
```

**Результат:**

```text
[5, 7, 9]
```
