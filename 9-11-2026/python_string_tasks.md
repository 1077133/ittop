# Задачи по Python: ord(), chr(), string и строки

## ord() и chr()

### 1. Код символа и его соседи
Пользователь вводит один символ. Выведи его код Unicode, а также предыдущий и следующий символы по кодовой таблице. Считай, что у введённого символа есть оба соседа.

Пример: `B` → `66`, `A`, `C`.

### 2. Расстояние между буквами
Даны две строчные английские буквы. Определи, сколько букв находится между ними в алфавите. Порядок ввода не важен.

Примеры: `a e` → `3`, `e a` → `3`, `a a` → `0`.

### 3. Шифр Цезаря
Даны строка из строчных английских букв и число сдвига `k ≥ 0`. Сдвинь каждую букву на `k` позиций вперёд. После `z` снова идёт `a`. Пробелы оставь на месте.

Пример: `xyz abc`, сдвиг `3` → `abc def`.

## Модуль string

Используй `import string` и подходящие константы: `ascii_letters`, `ascii_lowercase`, `ascii_uppercase`, `digits`, `punctuation`.

### 4. Подсчёт символов
Посчитай в строке количество:
- английских букв;
- цифр от `0` до `9`;
- знаков из `string.punctuation`;
- остальных символов.

Пример: `Hi, 42!` → букв `2`, цифр `2`, знаков `2`, остальных `2`.

### 5. Проверка пароля
Пароль подходит, если в нём есть хотя бы одна строчная английская буква, одна заглавная, одна цифра и один символ из `string.punctuation`, а длина — не меньше 8 символов. Пробелы запрещены.

Выведи `Подходит` или перечисли невыполненные условия.

### 6. Недостающие буквы
Пользователь вводит строку. Выведи по алфавиту все строчные английские буквы, которых в ней нет. Регистр при проверке не учитывай.

Пример: `Abc XYZ` → `defghijklmnopqrstuvw`.

## Работа со строками

### 7. Нормализация пробелов
Удали пробелы в начале и конце строки, а несколько пробелов между словами замени одним.

Пример: `"  Python   — это   интересно  "` → `"Python — это интересно"`.

### 8. Палиндром
Определи, читается ли строка одинаково слева направо и справа налево. Не учитывай регистр, пробелы и знаки препинания: оставь только буквы и цифры.

Пример: `А роза упала на лапу Азора!` → `Да`.

### 9. Сжатие строки
Замени каждую группу одинаковых подряд идущих символов на символ и количество повторений. Количество `1` тоже записывай. Считай, что исходная строка содержит только английские буквы.

Пример: `aaabbcaaaa` → `a3b2c1a4`.

Для пустой строки результат тоже должен быть пустым.
