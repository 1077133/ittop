# Python: списки, циклы, индексы и срезы

## Большой практикум — 150 задач

**Уровень:** от первых упражнений до комплексных задач.

**Что отрабатываем:** создание списков, `for`, `while`, `range`, `enumerate`, `zip`, вложенные циклы, положительные и отрицательные индексы, чтение и изменение срезов, все основные методы списков, встроенные функции, копирование и безопасное изменение списков.

Это сборник для нескольких занятий и самостоятельной работы. Не нужно выполнять все задания за одну пару. Готовых решений в сборнике нет. Небольшие примеры в условиях показывают формат результата.

## Как работать

- Каждую задачу оформляйте отдельной программой или функцией. В комплексных задачах используйте функции, если вы уже их изучили.
- Если способ ввода не задан, список можно записать прямо в программе. Для числового ввода допустима заготовка `a = list(map(int, input().split()))`.
- Индексы считаются с нуля. «Второй элемент» имеет индекс `1`. «Элементы с чётными индексами» — элементы с индексами `0, 2, 4, ...`.
- Исходный список не изменяйте, кроме задач, где это прямо требуется. «Изменить на месте» означает сохранить тот же объект списка.
- В задачах на ручной подсчёт используйте циклы; не заменяйте их `sum`, `min`, `max`, `count`, `index` или сортировкой, если это обходит требуемое действие. Ограничения конкретной задачи имеют приоритет.
- Не используйте сторонние библиотеки. Множества и словари применяйте только там, где это отдельно разрешено. Генераторы списков разрешены в разделе 11 и в дополнительных вариантах; остальные задачи решайте обычными циклами.
- Проверяйте результат хотя бы на трёх наборах: обычном, граничном и неудобном для вашего алгоритма. Если условие допускает пустой список, включайте его в проверки.
- Если задача просит предсказать результат или найти ошибку, сначала запишите ответ без запуска, затем проверьте его в Python.

### Полезные соглашения

- Срез `a[start:stop:step]` не включает границу `stop`. Отсутствующие границы зависят от направления шага. Шаг не может быть нулём.
- Отрицательный индекс отсчитывается от конца: `-1` — последний элемент. Чтение отдельного элемента за границами списка вызывает ошибку; границы среза могут выходить за длину списка.
- `a[:]` создаёт поверхностную копию: внешние списки различаются, но вложенные изменяемые объекты могут оставаться общими.
- В задачах со строками сравнение и сортировка выполняются по обычным правилам Python, без специальных правил русского алфавита.

## 1. Создание списков и первый перебор

### 1. Числа по порядку
Дано целое `n >= 0`. С помощью цикла и `append` создайте список чисел от `1` до `n` включительно. Для `n = 0` получите пустой список.

### 2. Квадраты
По данному `n >= 0` создайте список квадратов чисел от `0` до `n` включительно. Используйте цикл. Для `n = 4` результат: `[0, 1, 4, 9, 16]`.

### 3. Ввод до команды
Вводите целые числа по одному, пока пользователь не введёт строку `стоп`. Сохраните числа в списке и выведите его длину. Команда в список не попадает; её можно ввести первой. Используйте `while`.

### 4. Элемент на строку
Выведите элементы списка по одному на строке. Решите двумя способами: прямым перебором значений и перебором индексов через `range`.

### 5. Сумма вручную
Найдите сумму элементов числового списка циклом, без `sum`. Для пустого списка результат равен `0`.

### 6. Произведение вручную
Найдите произведение элементов циклом. Не используйте готовые функции произведения. Для пустого списка договоримся возвращать `1`. Проверьте список с нулём и список с отрицательными числами.

### 7. Счётчик знаков
За один проход посчитайте положительные, отрицательные и нулевые элементы. Выведите три количества. Для `[2, 0, -3, 5, 0]` это `2`, `1`, `2`.

### 8. Отбор чётных
Создайте новый список из чётных элементов исходного. Сохраните порядок и повторы. Для `[5, 2, 0, 2, -4]` результат: `[2, 0, 2, -4]`.

### 9. Замена по условию
Измените список на месте: все отрицательные числа замените нулями. Выполните присваивание по индексу внутри цикла. Длина списка должна сохраниться.

### 10. Числа больше среднего
Для непустого списка вычислите среднее арифметическое и создайте список элементов, строго больших среднего. Сумму считайте циклом. Если все числа одинаковы, результат пустой.

## 2. Индексы: прямые, отрицательные и вычисляемые

### 11. Края списка
Дан список длины не меньше двух. Выведите первый и последний элементы сначала с неотрицательными индексами, затем с отрицательными. Не используйте срезы.

### 12. Таблица индексов
Для каждого элемента выведите его значение, неотрицательный индекс и соответствующий отрицательный индекс. Для `[10, 20, 30]` у значения `10` должны получиться индексы `0` и `-3`. Используйте `enumerate`.

### 13. Безопасное обращение
Даны список и целый индекс `i`. Если индекс допустим, выведите элемент; иначе выведите `Нет такого индекса`. Поддержите отрицательные индексы. Не используйте обработку исключений. Пустой список также допустим.

### 14. Обмен краёв
Измените список на месте: обменяйте первый и последний элементы. Для длины `0` или `1` ничего не меняйте. Используйте индексы, без срезов и методов перестановки.

### 15. Центр
Если длина списка нечётная, выведите один центральный элемент; если чётная и ненулевая — два центральных элемента. Для пустого списка выведите `Центра нет`. Получайте элементы по индексам.

### 16. Обратный обход
Выведите список с конца к началу тремя способами: через отрицательные индексы в `for`, через убывающий `range` и через `while`. Не используйте срезы, `reverse` и `reversed`.

### 17. Чётный индекс или чётное значение
Создайте два списка: значения на чётных индексах и значения, которые сами являются чётными числами. Подберите пример, где результаты различаются. Используйте перебор с индексом, без срезов.

### 18. Соседние суммы
Создайте список сумм соседних элементов. Для `[3, 8, 2, 5]` результат: `[11, 10, 7]`. Для длины меньше двух верните `[]`. Используйте индексы.

### 19. Локальные вершины
Найдите индексы элементов, строго больших обоих соседей. Первый и последний элементы не рассматривайте. Для `[1, 4, 2, 5, 3]` результат: `[1, 3]`.

### 20. Зеркальные пары
Перебирайте пары «первый — последний», «второй — предпоследний» и так далее. Каждую пару выведите один раз вместе с индексами. Непарный центральный элемент нечётного списка выведите отдельно. Срезы запрещены.

## 3. Методы добавления, удаления и очистки

### 21. Пополнение по одному
Даны списки `a` и `b`. Добавьте все элементы `b` в конец `a` с помощью цикла и `append`. Затем повторите на свежих данных с помощью `extend`. Итоговое содержимое должно совпасть.

### 22. Один элемент или несколько
Для каждого варианта начните с нового списка `[1, 2]`: выполните `append([3, 4])`, `extend([3, 4])`, `append('ab')` и `extend('ab')`. Предскажите содержимое и длину. Затем проверьте и объясните различия.

### 23. Вставка перед найденным
Даны список, число `x` и значение `y`. Вставьте `y` перед первым `x` с помощью `insert`. Если `x` отсутствует, добавьте `y` в конец. Пустой список допустим.

### 24. Вставки за границами
Каждый раз начинайте с `[10, 20, 30]`. Исследуйте `insert(0, 99)`, `insert(100, 99)`, `insert(-1, 99)` и `insert(-100, 99)`. Перед запуском запишите ожидаемый результат. Сформулируйте правило для слишком больших и слишком маленьких индексов.

### 25. Удалить первое совпадение
Даны список и `x`. Удалите только первое вхождение `x` методом `remove`, если оно есть. Если его нет, оставьте список прежним. Не допускайте ошибки.

### 26. Извлечь элемент
Даны непустой список и допустимый индекс `i`, в том числе отрицательный. С помощью `pop` получите удалённое значение, затем выведите это значение и оставшийся список. Отдельно исследуйте вызов `pop()` без аргумента.

### 27. Удалить все совпадения
Даны список и `x`. Удалите все вхождения `x` на месте с помощью `while` и `remove`. Не используйте срезы. Проверьте соседние повторы, например `[2, 2, 3, 2]`.

### 28. Удаление по индексам
Даны список и список различных допустимых неотрицательных индексов. Удалите отмеченные элементы через `pop`, сохранив порядок остальных. Сначала определите безопасный порядок удаления. Например, для `[10, 20, 30, 40, 50]` и `[1, 3]` результат: `[10, 30, 50]`.

### 29. Очистить общий список
Создайте `a = [1, 2, 3]` и `b = a`. В одном опыте выполните `a.clear()`, в другом — `a = []`. Выведите `a`, `b` и результат `a is b` в каждом опыте. Объясните наблюдение.

### 30. Стек команд
Реализуйте команды `push x`, `pop`, `show`, `clear`, `stop` для одного списка. `push` добавляет элемент в конец, `pop` извлекает последний и выводит его. Для пустого стека выводите `Стек пуст`. Используйте методы списка и цикл обработки команд.

## 4. Поиск, подсчёт, сортировка и копирование

### 31. Частота значения
Даны список и `x`. Посчитайте вхождения `x` сначала циклом, затем методом `count`. Для отсутствующего значения и пустого списка оба способа должны дать `0`.

Найдите индекс первого вхождения `x` двумя способами: циклом и методом `index`. Если значения нет, выводите `Не найдено`. В варианте с `index` сначала проверьте наличие элемента.

### 33. Поиск внутри диапазона

Найдите все индексы вхождения `x`. Используйте `enumerate` и новый список. Для `[4, 7, 4, 4]` и `x = 4` результат: `[0, 2, 3]`. Одного вызова `index` недостаточно.

### 35. Сортировка на месте
Отсортируйте список чисел на месте методом `sort` сначала по возрастанию, затем по убыванию. Проверьте повторы и отрицательные числа. Отдельно выведите значение, которое возвращает вызов `sort`.

### 36. Сортированная копия
Получите возрастающую и убывающую версии списка через `sorted`. Исходный список должен сохранить порядок. Покажите разницу между результатом `sorted(a)` и возвращаемым значением `a.sort()` на отдельных копиях.

### 37. Сортировка по правилу
Дан список слов. Получите новую версию, отсортированную по длине через `sorted(..., key=len)`. При равной длине сохраните исходный порядок. Затем отсортируйте список целых по абсолютной величине с `key=abs`.

### 38. Три разворота
Получите обратный порядок с помощью `reverse`, `reversed` и среза. Во втором варианте преобразуйте результат в список. Укажите, какой способ изменил исходный объект, и исследуйте возвращаемое значение `reverse`.

### 39. Три поверхностные копии
Создайте копии плоского списка тремя способами: `copy`, `list(a)` и `a[:]`. Измените по одному элементу каждой копии. Проверьте, что исходный список не изменился и каждая копия — отдельный объект.

### 40. Сводка встроенными функциями
Для числового списка выведите длину, сумму, минимум, максимум, `any(a)` и `all(a)`. Для пустого списка вместо минимума и максимума выводите `Нет элементов`. Проверьте `[]`, `[0, 0]`, `[0, 3]`, `[-2, 3]` и объясните результаты `any` и `all`.

## 6. Отрицательный шаг и тонкости границ

В задачах 51–60 сначала выписывайте индексы, затем значения. Для предсказаний используйте `a = list(range(10))`, если другое не указано.

## 14. Комплексные задачи

### 131. Редактор списка
Реализуйте команды `add x`, `insert i x`, `remove x`, `pop i`, `set i x`, `show`, `clear`, `stop`. Для `pop` и `set` поддержите отрицательные индексы; недопустимый индекс обрабатывайте сообщением. `remove` удаляет первое совпадение или сообщает об отсутствии. Для `insert` используйте стандартное поведение метода, включая индексы за границами. После каждой изменяющей команды выводите текущее содержимое. Формат команд считайте корректным.

### 132. Журнал оценок
Дан список целых оценок от `2` до `5`. Выведите количество каждой оценки через `count`, среднее арифметическое, индексы двоек и новый отсортированный список. Затем измените журнал: замените все двойки тройками по индексам. Для пустого журнала сообщите, что среднее не определено; остальные результаты должны оставаться корректными.

### 133. Очередь обслуживания
Реализуйте команды `пришёл имя`, `обслужить`, `вставить i имя`, `ушёл имя`, `показать`, `стоп`. Имена — строки без пробелов, повторы допустимы. Обслуживание удаляет и выводит первого человека через `pop(0)`, уход удаляет первое совпадение. Вставку разрешайте только при `0 <= i <= len(queue)`. Пустую очередь и отсутствующее имя обрабатывайте сообщением.

### 134. Разбить на блоки
Даны список и целое `k > 0`. Создайте список непересекающихся блоков длины `k` с помощью цикла и срезов. Последний блок может быть короче. Для `[1, 2, 3, 4, 5]` и `k = 2` результат: `[[1, 2], [3, 4], [5]]`. Затем разверните каждый второй блок с индексом `1, 3, 5, ...`.

### 135. Окно с наибольшей суммой
Даны список и целое `k`. Найдите индекс начала, сам срез и сумму первого окна длины `k` с максимальной суммой. Используйте один проход с обновлением суммы окна. При `k <= 0` или `k > len(a)` выводите `Нет допустимых окон`. Проверьте список только из отрицательных чисел.

### 136. Циклическое совпадение
Даны два списка. Определите, можно ли получить второй циклическим сдвигом первого. Если можно, найдите минимальный неотрицательный сдвиг вправо. При разных длинах совпадение невозможно; для двух пустых списков ответ — сдвиг `0`. Используйте цикл и срезы, учитывайте повторы.

### 137. Все вхождения фрагмента
Даны список `a` и непустой список-образец `pattern`. Найдите все индексы начала непрерывного фрагмента, равного образцу. Перекрывающиеся совпадения учитывайте. Для `[1, 1, 1]` и `[1, 1]` результат: `[0, 1]`. Используйте цикл и сравнение срезов. Если образец длиннее списка, результат пустой.

### 138. Замена фрагментов
Даны `a`, непустой `pattern` и список `replacement`. Создайте новый список, заменяя неперекрывающиеся вхождения образца слева направо. Вставленные элементы повторно не проверяйте; `replacement` может быть пустым. Для `[1, 1, 1]`, образца `[1, 1]` и замены `[9]` результат: `[9, 1]`. Используйте `while`, срезы и `extend`.

### 139. Палиндромный участок
Найдите самый длинный непрерывный участок, одинаково читающийся слева направо и справа налево. При равных длинах верните первый. Используйте вложенные циклы, срезы и обратный срез. Для пустого списка верните `[]`. Для `[1, 2, 3, 2, 1, 9]` результат: `[1, 2, 3, 2, 1]`. Быстродействие пока не оценивается.

### 140. Сортировка вставками
Отсортируйте числовой список на месте по возрастанию алгоритмом вставок: очередной элемент сохраняйте, большие элементы слева сдвигайте вправо циклом `while`, затем ставьте сохранённый элемент в освободившуюся позицию. Не используйте `sort`, `sorted` и второй список. Проверьте пустой список, повторы, прямой и обратный порядок.

## 15. Итоговые испытания

### 141. Один результат — три способа
Создайте список элементов исходного списка, которые стоят на нечётных индексах, в обратном порядке. Решите: циклом с индексами; последовательностью срезов; одним срезом. В варианте с одним срезом учитывайте чётность длины. Все три решения должны совпасть для длины от `0` до `10`.

### 142. Срез без синтаксиса среза
Напишите функцию `manual_slice(a, start, stop, step)`, возвращающую тот же список, что `a[start:stop:step]`. Границы могут быть `None` и выходить за список; шаг — ненулевое целое. ### 143. Перестановка чётных и нечётных
Дан список чётной длины. Создайте новый список, где сначала идут элементы исходного с чётными индексами, затем с нечётными. Затем напишите обратное преобразование, восстанавливающее исходный порядок. Для `[10, 20, 30, 40, 50, 60]` промежуточный результат: `[10, 30, 50, 20, 40, 60]`. Используйте срезы и присваивание расширенным срезам.

### 144. Разворот каждого слова в списке символов
Дан список отдельных символов, где слова разделены символом `' '`. Разверните символы каждого слова на месте, сохранив позиции всех пробелов. Например, `list('кот  дом')` должно превратиться в `list('ток  мод')`. Используйте индексы и обмены или изменение срезов. Запрещены `split`, `join` и сборка новой строки.

### 145. Удалить повторы на месте
Дан список, отсортированный по неубыванию. Удалите повторы, сохранив каждое значение один раз. Используйте индекс чтения и индекс записи, а затем удалите ненужный хвост срезом. Не применяйте `remove`, `count`, множества, словари и второй список. Итоговый объект списка должен остаться тем же.

### 146. Переместить блок
Даны `a`, границы блока `0 <= left <= right <= len(a)` и позиция `0 <= p <= len(a) - (right - left)`. Вырежьте блок `[left, right)` и вставьте его перед позицией `p` в оставшемся списке. Изменяйте `a` на месте срезами. Позиция `p` относится именно к списку после удаления. Например, `[0, 1, 2, 3, 4, 5]`, `left = 1`, `right = 3`, `p = 3` дают `[0, 3, 4, 1, 2, 5]`.

### 147. История изменений

### 148. Мини-лаборатория срезов

### 150. Итоговый анализатор последовательности

Создайте программу, которая выводит: длину; сумму; количество положительных, отрицательных и нулей; минимум и максимум с индексами первых вхождений; список без повторов; самый длинный возрастающий непрерывный участок; сжатие серий; элементы с чётными индексами в обратном порядке; возрастающую копию. Ручные подсчёты, поиск экстремумов, удаление повторов и обработку серий выполните циклами; сортированную копию получите через `sorted`, срез — штатным выражением. ## Как оценить готовое решение

1. Программа решает именно указанную задачу и соблюдает ограничения на способы решения.
2. Совпадения, повторы и равные экстремумы обрабатываются по условию.
3. Индексы и границы не выходят за допустимые пределы при обращении к отдельным элементам.
4. Пустой список и короткие списки обработаны там, где они разрешены.
5. Исходный список сохраняется либо меняется на месте — в соответствии с условием.
6. Проверены граничные случаи: отрицательные индексы, большой шаг, отрицательный шаг, пустой участок и крайние позиции.
7. Автор может объяснить, почему цикл завершается и почему каждый нужный элемент обработан ровно столько раз, сколько требуется.
